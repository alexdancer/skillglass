# Choose the first distinctive workflow

Type: grilling
Status: resolved
Parent: [Skill Viewer: product direction and constraints](../map.md)

## Question

Which distinctive workflow would most improve the user's day beyond listing, reading, and toggling skills?

## Candidates

- Explain availability: choose an agent and project, then see why a skill is available, disabled, hidden, or uncertain.
- Compare duplicates: distinguish shared references, identical independent copies, and diverged versions before cleanup.
- Preview and undo a batch: stage several availability changes and inspect their combined effect. Undo does not apply to permanent deletion.
- Named profiles: save a chosen set of skills for a kind of work and apply it deliberately.
- Personal reading library: favorites, private notes, custom tags, and search through full skill text.

These are proposals, not promised novel inventions or accepted features. Do not infer usage frequency from file modification times or equate installed files with active context cost.

## Answer

The user accepted the recommendations on October 10, 2026: prioritize **explaining availability** and **comparing duplicate or diverged copies** as the first distinctive workflows.

The other candidate features are not first-release commitments. Normal browsing, reading, cleanup, and availability controls remain core goals. Exact cleanup actions are a separate product decision.
