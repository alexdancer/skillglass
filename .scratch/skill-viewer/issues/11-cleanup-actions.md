# Choose first-release cleanup actions

Type: grilling
Status: resolved
Parent: [Skill Viewer: product direction and constraints](../map.md)

## Question

Should the first release identify problems, compare copies, and let the user choose disable or delete actions, or should it also repair links and consolidate independent duplicate copies?

## Context

The user has chosen duplicate comparison as a distinctive workflow. Detection and comparison do not themselves authorize repair, consolidation, or deletion. Permanent deletion requires confirmation.

Recommendation awaiting the user: focus first on identifying problems, comparison, and explicit disable/delete choices.

## Answer

The user chose **find problems, compare copies, and let me choose disable or delete** on October 10, 2026. Link repair, automatic consolidation, and automatic cleanup are not first-release requirements. Permanent deletion remains a separate confirmed action.
