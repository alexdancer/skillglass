# Triage labels

Map the five canonical triage roles to the existing labels in the Alex Dancer (ALE) Linear team.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent once blockers are resolved |
| `ready-for-human` | `ready-for-human` | Requires human participation or implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a triage role, use the corresponding label above. These labels already exist; reuse them. Preserve unrelated labels. Triage labels do not replace Linear workflow states or dependency checks.

Edit the Linear label column if the vocabulary changes later.
