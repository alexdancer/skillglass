# ALE-25 comparison verification

ALE-25 adds the shared `Snapshot.Compare` operation for CLI and browser comparison. The [README](../../README.md#build-and-use) owns current commands, identity semantics, JSON fields, browser controls and exit statuses. This document owns detailed comparison limits, consistency policy and ALE-25 coverage; the [ALE-24 guide](ale-24.md#reproduce-the-acceptance-evidence) owns current combined-suite verification procedures.

## Behavior and limits

Manifests must be readable regular files, directly or through a manifest link; readable malformed manifests are still compared as raw bytes. Missing, unobserved or non-regular manifests produce coverage issues. Binary classification uses invalid UTF-8 or control characters other than newline, carriage return and tab. Supporting links are compared as link entries without reading target bytes. Missing/cyclic targets, external targets, unreadable entries and special files make coverage incomplete. A linked manifest is explicitly read with target consistency evidence; an external linked manifest remains incomplete even if its observed bytes match. Paths hidden by failed directory reads, inventory truncation, unavailable sources or excluded supporting links are reported with `status: unknown`, `kind: unknown` and no diff when absence cannot be established from the observed inventory. A stable observed non-directory, non-link ancestor proves descendants absent, even when its bytes are unreadable or exceed the read limit; unreadable directories and untraversed links do not.

Each observation pass is bounded to 10,000 entries per side (including the bundle root), 64 MiB of observed regular-file bytes per side and 8 MiB per file. Manifest link target bytes count toward the read budget. Diff output uses a 1,000-line threshold per changed file, including headers; a final no-newline marker can exceed that threshold by one. Content excerpts retain at most 4,096 UTF-8 bytes before adding the diff prefix and truncation annotation. Path-bearing headers are not subject to that byte limit, and terminal escaping can expand rendered lines. Link text is read into a 4,096-byte buffer.

Regular reads use nonblocking, no-follow descriptor-relative traversal anchored from `/`; FIFOs, sockets and devices are never read or executed. Access times are excluded from consistency stamps because reading may update them. Directory membership, object identity, modes, sizes, modification/change times and byte hashes are observed across two passes, with per-open and per-read checks. Detected changes produce coverage issues. This is best-effort stable observation, not an atomic snapshot; changes that restore all observable evidence between checks can evade detection.

Comparison completion carries a generation token, and a canceled or superseded request cannot replace the current browser view. Opening Help does not cancel the comparison: completion updates the underlying result without closing Help, and returning reveals the completed comparison. The deterministic regression in `internal/terminal/verify_compare_help_test.go` and terminal journey in `tests/acceptance/verify_compare_help_test.go` cover this boundary.

An unknown missing-counterpart membership makes comparison coverage incomplete with a side/path explanation, even when an internal link target is inventoried elsewhere; identical internal links alone do not force incomplete coverage.

## Acceptance evidence

- Public executable tests cover equal independent copies, divergent instructions, added/removed text, binary differences, mode/kind changes, empty directories, malformed raw manifests, shared references, independently shared manifests and divergent support.
- Incomplete coverage tests exercise external/broken/cyclic links, unreadable files, FIFOs, oversized resources and linked manifests. `TestReviewComparisonRequiresRegularManifest` rejects directory and linked-directory manifests while retaining readable internal manifest links. `TestReviewComparisonUnobservedMembership` checks unknown membership beneath unreadable directories and entry-limited inventories in both directions while retaining proven additions/removals. `TestReviewComparisonUnavailableSourceMembership` covers a selected source becoming missing or unreadable. `TestReviewComparisonAncestorTypeProvesMembership` checks proven descendant additions/removals beneath file ancestors and unknown membership beneath unreadable directories or links, in both directions. `TestReviewComparisonUnknownChildLimitsCoverage` requires a side/path coverage issue for unknown membership while preserving known differences; `TestReviewComparisonIdenticalInternalLinksComplete` checks that identical internal links alone do not limit coverage.
- Output tests exercise escaped filenames, unknown selections, exact final-newline differences, bounded diff presentation and independent discovery-scope coverage. `TestReviewComparisonLongLineNewlineEvidence` checks final-newline markers independently of line truncation.
- Before/after tree manifests include all fixtures, external targets and unrelated settings. Bundled executable scripts would create a sentinel if run; the sentinel remains absent.
- Real tmux tests at 48, 60, 80 and 120 columns select same-name independent rows, show marked source path and ID, compare content edited after discovery, scroll full differences, cancel, replace the selected directories outside scope, reject stale identity, and refresh the mark away. Captured cells enforce width and height constraints.
- Private deterministic read-observer tests induce equal-size rewrites, rename/add/remove, manifest link replacement, selected-parent link substitution and ancestor-type replacement at a controlled traversal point. This narrow private seam covers filesystem timing that cannot be reliably induced via public executable commands. There is no public test flag or environment backdoor.
